# QIMA-BIBD

## Constraint-Preserving Quantum-Inspired Memetic Algorithm for Balanced Incomplete Block Designs

This repository accompanies the research paper **A Constraint-Preserving
Quantum-Inspired Memetic Algorithm for the Construction of Balanced
Incomplete Block Designs**.

### Features

-   Faithful QUBO/Ising formulation
-   Rosenberg quadratization
-   Constraint-preserving block-set representation
-   Quantum-inspired probability register
-   Rotation-gate updates
-   Adaptive penalties
-   Pair-frequency-aware local search
-   Iterated Local Search (ILS)
-   Reproducible experiments on CSPLib Problem 028
